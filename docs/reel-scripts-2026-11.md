**わかったこと**

1. **伸びたのは「期限＋具体的なケア」と「自分で確かめられるチェック」**。9/17は保存1,076・平均32秒と別格。9/24（左右差チェック）も2位。
2. **気持ち・考え方から入るリールは最初の3秒で6〜7割が離脱**（10/4・10/7・9/20）。共感の話は、ケアの後半か字幕に回すほうが良い。
3. 同じ「年末まで◯日」でも、9/29はケアの中身がぼやけていて伸びなかった。**期限だけでは弱く、「何を・何回」まで冒頭で言い切る**ことが大事。
4. 保存されるのは「回数・秒数つきの手順」。寝る前・座ったままなど、**やる場面が決まっているもの**。
5. 10月以降はリーチ600〜1,500で落ち着いている。年末に向けて、9/17の型をもう一度使うのが一番確実。

外部の情報でも、冒頭2秒の作り込み・数字を入れる・次の行動を1つに絞ることが勧められていました（下の出典）。

## 3. 撮るときのポイント（データから）

- **最初の1秒は「誰に」「何を」を文字で言い切る**。気持ちの話・自分の話から始めない（離脱60〜70%だった）。
- **回数・秒数を必ず字幕に入れる**。保存の理由になる。
- 締めの行動は1つだけ（保存 or コメント）。LINEの案内はキャプションに回す。
- 9/17の勢いがあった時期に近い、**台本A → C → B** の順がおすすめ（週2本ペース）。
- 投稿から1週間後に、リーチ・保存・平均視聴時間・3秒離脱を上の表と比べる。
