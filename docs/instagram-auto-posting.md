# Instagram自動投稿（@seitai_cocowa）

Notionの「投稿リスト」に入れた投稿を、Claudeの定期実行（ルーティン）が自動でInstagramに投稿する仕組みです。

## 構成

| 役割 | 内容 |
|---|---|
| 投稿リスト | Notion「Instagram自動投稿（@seitai_cocowa）」ページ内のデータベース「投稿リスト」 |
| 実行 | Claudeのスケジュールタスク「Instagram自動投稿2」 毎日 7:03 / 12:03 / 18:03（日本時間） |
| 投稿 | Windsor.ai の Instagram 連携（account 17841401645289862） |

タスクは claude.ai/code/routines の画面から作成し、Notion と Windsor.ai のコネクタを含めています。

## 投稿リストの項目

| 項目 | 説明 |
|---|---|
| タイトル | 自分用の名前（Instagramには出ない） |
| 種類 | カルーセル / 画像 / ストーリー |
| 画像 | JPEGのみ・1枚8MBまで。カルーセルは2〜10枚（並び順が投稿順） |
| キャプション | 2200文字まで。ストーリーは不要 |
| 投稿日時 | この日時を過ぎた次の実行で投稿される |
| ステータス | 下書き → 予約OK → 投稿済み / エラー |
| 画像の文字 | ストーリーの画像に入れる文字（改行した位置で改行） |
| 加工済み画像 | ストーリー用に自動で作られる画像 |
| 投稿完了日時・メモ | 自動で書き込まれる（メディアIDやエラー理由） |

## 処理の流れ

1. ステータスが「予約OK」で、投稿日時が現在時刻を過ぎている行を古い順に取り出す
2. 画像の形式・枚数・キャプションの長さを確認する
3. 種類に応じて `create_carousel_post` / `create_image_post` / `create_story` を実行する
4. 成功したら「投稿済み」、失敗したら「エラー」にしてメモに理由を書く

動画・リールはこの仕組みの対象外です（手動で投稿します）。

## 運用の目安

- カルーセル：週3本（月・水・金）
- 画像1枚：週2本（火・土）
- ストーリー：毎日2本（朝：豆知識・セルフケア／夕方：投稿紹介・院内の様子）

## 画像の自動作成

投稿の直前に `scripts/make_post_images.py` で投稿用の画像を作り、「加工済み画像」に保存してから投稿します。

| 種類 | 作り方 |
|---|---|
| ストーリー | 1080×1920。写真があれば切らずに収め、上に「画像の文字」。写真がなければ文字だけ |
| 画像 | 1080×1350。写真＋「画像の文字」、または文字だけ |
| カルーセル | 1080×1350。「スライド文字」（`---` 区切り）から各スライドを作る。写真は先頭のスライドから順に使う |

下の帯には「整体院 心和｜所沢」が入ります。

## 下書きの自動補充

毎回の実行で、明日から7日先までの空いている枠に下書きを作ります（1回最大8行）。

- 月・水・金 7:00 カルーセル／火・土 7:00 画像
- 毎日 7:00・18:00 ストーリー（文字だけ）

写真は「写真ストック」から使用回数の少ないものを選び、合うものがなければ Pixabay（`scripts/pixabay_photo.py`）から取ります。下書きは「下書き」のまま作られ、確認して「予約OK」にしたものだけが投稿されます。
